How it works
  1. Read a step, then answer on the right. A step is one prompt from the human plus everything the coding agent did next. Say whether it helped, mark any mistake the agent made, and label the prompt.
  2. Use the evidence. The tabs under each step show what the agent said, the files it changed, the tests it ran and every action. The finished repo is under Final build.
  3. Grade the session last. Wrap up lists the mistakes you marked. After you grade the session, the build's result appears with one last question.

Answers save as you go. Inside a task, press ? for the labelling guide, with definitions, worked examples and keyboard shortcuts.
